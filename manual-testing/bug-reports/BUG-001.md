# BUG-001: Цены товаров отображаются некорректно у problem_user

**Окружение:** Chrome 126, https://www.saucedemo.com/
**Пользователь:** problem_user / secret_sauce

## Шаги воспроизведения
1. Авторизоваться как `problem_user`
2. Перейти на страницу каталога товаров (/inventory.html)
3. Изменить сортировку на "Price (low to high)"

## Ожидаемый результат
Товары должны отсортироваться по возрастанию цены.

## Фактический результат
Порядок товаров не меняется после смены сортировки — остаётся прежним.

## Severity / Priority
- Severity: Medium (нарушена функция, но не блокирует работу приложения)
- Priority: Medium
