# BUG-002: Отсутствует сообщение об ошибке при пустом поле Username

**Окружение:** Firefox 128, https://www.saucedemo.com/

## Шаги воспроизведения
1. Открыть страницу логина
2. Оставить поле Username пустым
3. Заполнить поле Password любым значением
4. Нажать кнопку Login

## Ожидаемый результат
Отображается сообщение об ошибке "Username is required"
