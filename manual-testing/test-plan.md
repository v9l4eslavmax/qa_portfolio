# Test Plan: SauceDemo Web Application

## 1. Цель тестирования
Проверить корректность работы основного функционала интернет-магазина SauceDemo: авторизация, каталог товаров, корзина, оформление заказа.

## 2. Объект тестирования
- URL: https://www.saucedemo.com/
- Тип: веб-приложение (демо-магазин)

## 3. Scope (что тестируем)
- Авторизация (валидные/невалидные пользователи, разные типы пользователей)
- Каталог товаров (отображение, сортировка, фильтрация)
- Корзина (добавление/удаление товаров)
- Оформление заказа (checkout flow)

## 4. Out of scope
- Нагрузочное тестирование
- Тестирование безопасности
- Тестирование мобильной версии

## 5. Стратегия тестирования
- **Функциональное тестирование** — вручную (тест-кейсы) и автоматизированно (Playwright)
- **Позитивные и негативные сценарии**
- **Кросс-браузерное тестирование** — Chrome, Firefox

## 6. Типы пользователей (тестовые данные)
| Логин | Особенность |
|---|---|
| standard_user | обычный пользователь |
| locked_out_user | заблокирован |
| problem_user | UI-баги |
| performance_glitch_user | задержки |

Пароль для всех: `secret_sauce`

## 7. Критерии входа/выхода
**Вход:** тестовое окружение доступно, тестовые данные подготовлены.
**Выход:** все критичные и высокоприоритетные тест-кейсы выполнены, критичных багов нет.

## 8. Риски
- Демо-сайт может менять поведение без предупреждения (сторонний ресурс)

## 9. Инструменты
- Test cases: Markdown / Excel
- Баг-трекинг: GitHub Issues
- Автоматизация: Playwright + pytest
- CI: GitHub Actions
